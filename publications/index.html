2026

  1. DISC
    Approximating Minimum Dominating Set with Few Awake Rounds
    Hongyan Ji, Shreyas Pai, and Sriram V. Pemmaraju
    In 40th International Symposium on Distributed Computing, 2026
    To appear at DISC 2026
    arXiv

    We study Minimum Dominating Set in the sleeping CONGEST model, where nodes may sleep and can compute or communicate only while awake. We give the first O(log Δ)-approximation algorithm with o(log² Δ) awake complexity: it runs in O(log² Δ) rounds with Õ(log Δ) awake complexity. We also establish a trade-off between approximation quality and awake complexity.

  2. TCS
    Faster Set Cover in the MPC Model
    Hongyan Ji, Shreyas Pai, Sriram V. Pemmaraju, and Joshua Sobel
    Theoretical Computer Science, 2026
    Journal version; Volume 1086, Article 116238
    DOI PDF

    The Massively Parallel Computation (MPC) model is a popular abstraction for large-scale distributed computing. For Set Cover with n elements and m sets, we give two O(log n)-approximation algorithms. They run in Õ(log N) rounds in the linear-memory MPC model and Õ(log¹·⁵ N) rounds in the sublinear-memory MPC model, where N = n + m. These are the first O(log n)-approximation algorithms for Set Cover in this setting that run in o(log² N) rounds.

2025

  1. ICDCN
    Fast Deterministic Massively Parallel Ruling Sets Algorithms
    Hongyan Ji, Kishore Kothapalli, Sriram V. Pemmaraju, and Ajitanshu Singh
    In Proceedings of the 26th International Conference on Distributed Computing and Networking, 2025
    DOI PDF

    We give a deterministic Õ((log Δ)^(1/3))-round algorithm for the 2-ruling set problem in the sublinear-memory MPC model, improving on the previous Õ(sqrt(log n))-round bound. The result derandomizes the sample-and-gather approach, which requires fixing randomness for a batch of future iterations. We extend the approach to β-ruling sets and to bounded-arboricity graphs.

  2. ICDCN
    Faster Set Cover in the MPC Model
    Hongyan Ji, Shreyas Pai, Sriram V. Pemmaraju, and Joshua Sobel
    In Proceedings of the 26th International Conference on Distributed Computing and Networking, 2025
    Conference version
    DOI PDF Award certificate

    For Set Cover with n elements and m sets, we give O(log n)-approximation algorithms that run in Õ(log N) rounds in the linear-memory MPC model and Õ(log¹·⁵ N) rounds in the sublinear-memory MPC model, where N = n + m. We obtain these results by adapting sparsified graph exponentiation, previously used for maximal independent set, to a distributed Set Cover algorithm.

    Best Paper Award, Distributed Computing Track, ICDCN 2025

2024

  1. SIROCCO
    Towards Singular Optimality in the Presence of Local Initial Knowledge
    Hongyan Ji, and Sriram V. Pemmaraju
    In International Colloquium on Structural Information and Communication Complexity, 2024
    DOI PDF

    The Knowledge Till ρ (KT-ρ) CONGEST model gives each node initial knowledge of its radius-ρ neighborhood. We show that radius-2 initial knowledge substantially improves the round-message trade-off for constructing a sparse communication backbone, or danner. The construction yields improved algorithms for broadcast, leader election, spanning tree, minimum spanning tree, and coloring in the KT-2 CONGEST model.
